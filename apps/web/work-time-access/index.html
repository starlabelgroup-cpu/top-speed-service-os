The Master's account console for the whole Top Speed ecosystem — create accounts and choose passwords for every platform, website, landing page and app access point, manage employee numbers, and control each account's 2-step sign-in. Master account only.

How sign-in works — one 2-step system

STEP 1Password

The account holder signs in with their email and the password set here (they can change it later from their own account).

STEP 2Verification code

Speedy Verify first, where the account requires it: the 8-digit access code only the Master issues. Then Layer 2: a 6-digit code sent to the holder's email or phone.

STEP 3Signed in

Both steps passed — the session opens on the account's own surface, and nowhere else. Portal doors stay separated by account type.

New staff and business / property-manager accounts start with Speedy Verify required and wait for your code before their first sign-in. Every new account starts with Layer 2 on. The Master account is exempt from both steps by Rule Zero — it can never be locked out.
