# Web app placeholder

`index.html` in this folder is the current static Top Speed Ecosystem landing page and booking-form placeholder. It is intentionally preserved.

The future customer/provider web experience is planned as one React + Vite codebase that can serve both public domains from the shared Service OS API:

- `topspeedappliance.net` — customers, bookings, and property managers
- `topspeedapplianceservice.com` — provider network

This Phase 1 starter does not replace the current production website and does not claim that the static form saves bookings end to end. The runnable booking-to-dispatch skeleton is in `apps/api`; the native booking UI is a later phase.
